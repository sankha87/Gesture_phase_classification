# Dataset

`phpYLeydd.arff` contains the gesture phase classification data used by the project notebook.

## Summary

- Format: Attribute-Relation File Format (ARFF)
- Instances: 9,873
- Predictors: 32 numeric attributes (`X1` through `X32`)
- Target: `Phase`
- Target classes: `D`, `H`, `P`, `R`, and `S`

## Class distribution

| Class | Instances |
| --- | ---: |
| D | 2,741 |
| H | 998 |
| P | 2,097 |
| R | 1,087 |
| S | 2,950 |

The file is a direct, unmodified copy of the ARFF source supplied with the project. The notebook also retrieves the corresponding dataset through OpenML data ID 4538.
